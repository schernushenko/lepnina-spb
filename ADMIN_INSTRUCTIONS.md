# Инструкция по использованию админ-панели

## Доступ к админке

1. **Ссылка на админку**: В навигации сайта есть ссылка "Админка"
2. **Учетные данные по умолчанию**:
   - Логин: `admin`
   - Пароль: `admin123`

## Изменение учетных данных

Учетные данные хранятся в файле `config.json` в корне проекта:

```json
{
  "admin": {
    "username": "ваш_логин",
    "password": "ваш_пароль"
  },
  ...
}
```

**Важно**: После изменения файла config.json необходимо перезапустить сервер!

## Возможности админ-панели

### 1. Управление работами (портфолио)
- **Добавление новой работы**: 
  - Введите название работы
  - Укажите путь к изображению (например: `/new-work.jpg`)
  - Загрузите изображение в папку `public/`
- **Редактирование работ**:
  - Изменение названия
  - Скрытие/показ работы (кнопка "Скрыть"/"Показать")
  - Удаление работы (помечает как неактивную)

### 2. Настройки компании
- **Название компании**: Отображается в заголовке главной страницы
- **Телефон**: Контактный телефон в разделе "Контакты"
- **Email**: Электронная почта в разделе "Контакты"
- **Описание**: Текст под заголовком на главной странице

### 3. Категории калькулятора
- В разделе «Калькулятор» можно создать или изменить категорию и загрузить для неё изображение.
- Изображение сохраняется вместе с категорией; для замены загрузите новый файл, для удаления нажмите «Удалить изображение».
- Поддерживаются JPG, PNG, WebP, GIF и AVIF; размер файла — до 20 МБ.

## Структура файлов

```
├── config.json              # Конфигурация сайта и учетные данные
├── app/data/
│   ├── works.json          # Список работ (генерируется автоматически)
│   └── config.ts          # Утилиты для работы с конфигурацией
├── app/admin/              # Админ-панель
│   ├── page.tsx           # Главная страница админки
│   └── login/page.tsx     # Страница входа
├── app/api/admin/         # API для админки
│   ├── login/route.ts     # Авторизация
│   ├── logout/route.ts    # Выход из системы
│   ├── config/route.ts    # Управление конфигурацией
│   └── works/route.ts     # Управление работами
└── middleware.ts          # Защита админских маршрутов
```

## Безопасность

1. **Хранение пароля**: Пароль хранится в открытом виде в config.json
2. **Защита маршрутов**: Все админские маршруты защищены middleware
3. **Сессии**: Используются HTTP-only куки с 24-часовым сроком действия

## Советы по использованию

1. **Изображения работ**:
   - Загружайте изображения в папку `public/`
   - Используйте оптимизированные изображения (рекомендуемый размер: 800x600px)
   - Поддерживаемые форматы: JPG, PNG, WebP

2. **Резервное копирование**:
   - Регулярно копируйте файлы `config.json` и `app/data/works.json`
   - Эти файлы содержат все настройки и данные сайта

3. **Безопасность**:
   - Измените пароль по умолчанию после первого входа
   - Не публикуйте файл config.json в публичном репозитории
   - Используйте .gitignore для исключения конфиденциальных файлов

## Устранение неполадок

### Проблема: Не могу войти в админку
**Решение**:
1. Проверьте правильность логина и пароля в config.json
2. Убедитесь, что сервер запущен
3. Перезагрузите страницу и попробуйте снова

### Проблема: Изменения не сохраняются
**Решение**:
1. Проверьте права на запись для файлов config.json и works.json
2. Убедитесь, что нажали кнопку "Сохранить настройки"
3. Перезагрузите страницу сайта для обновления кэша

### Проблема: Изображения не отображаются
**Решение**:
1. Проверьте правильность пути к изображению
2. Убедитесь, что изображение загружено в папку public/
3. Проверьте права доступа к файлу изображения
