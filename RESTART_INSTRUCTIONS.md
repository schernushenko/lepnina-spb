# Инструкция по перезапуску сервера

## Для применения изменений необходимо:

### 1. Остановить текущий сервер (если запущен)
Нажмите `Ctrl+C` в терминале, где запущен `npm run dev`

### 2. Запустить сервер заново
```bash
npm run dev
```

### 3. Проверить работу
1. Откройте браузер и перейдите по адресу: http://localhost:3000
2. Проверьте, что главная страница загружается без ошибок
3. Нажмите на ссылку "Админка" в навигации
4. Войдите с логином `admin` и паролем `admin123`

## Что было исправлено:

### 1. **Middleware обновлен для Next.js 16.3.0**
- Старый `middleware.ts` заменен на `app/proxy.ts`

### 2. **API маршруты переписаны**
- Устранены проблемы с чтением файлов на сервере
- Добавлена загрузка данных в память при запуске
- Улучшена обработка ошибок

### 3. **Главная страница обновлена**
- Добавлена обработка ошибок загрузки данных
- Резервные данные при недоступности API

## Если проблемы сохраняются:

### 1. Очистите кэш браузера
- Откройте DevTools (F12)
- Перейдите на вкладку "Network"
- Установите галочку "Disable cache"
- Обновите страницу (Ctrl+F5)

### 2. Проверьте консоль браузера
- Откройте DevTools (F12)
- Перейдите на вкладку "Console"
- Проверьте наличие ошибок

### 3. Проверьте консоль сервера
- В терминале с `npm run dev` проверьте логи
- Убедитесь, что нет ошибок компиляции

## Тестирование API:
Для проверки работы API можно запустить тестовый скрипт:
```bash
node test-api.js
```

## Контактная информация:
Если проблемы не решены, проверьте:
1. Файл `config.json` существует и содержит корректный JSON
2. Файл `app/data/works.json` существует и содержит корректный JSON
3. Сервер имеет права на чтение/запись этих файлов
